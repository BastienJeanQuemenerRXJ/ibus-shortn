This is an IBus engine for Shortn.



Note that the actual input logic is handled by
[libshortn](https://github.com/BastienJeanQuemenerRXJ/ibus-shortn).

Development happens [on github](https://github.com/BastienJeanQuemenerRXJ/ibus-shortn)
